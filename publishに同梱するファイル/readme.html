エディタについて

danoniplus互換の譜面ファイル(dos.txt)を作成するための編集ソフトです。1ウィンドウ=1曲(複数難易度タブを内包)構成で、FUJIエディタ・SKBエディタ・既存dos.txtからのインポートにも対応しています。

起動時の注意(発行元不明の警告)

このエディタのexeを別の環境で起動すると、Windowsが「不明な発行元です」「WindowsによってPCが保護されました」といった警告を表示することがあります。これはエディタ自体の不具合ではなく、実行ファイルにコード署名(デジタル署名)が付いていないために起こる、Windows標準のSmartScreen機能の挙動です。個人配布の無償ツールでは一般的なことで、ウイルス感染等を意味するものではありません。

警告が出た場合は、ダイアログの「詳細情報」をクリックし、表示された「実行」ボタンを押すことで起動できます。根本的に警告を無くすには有償のコード署名証明書を取得して署名する必要がありますが、無料の自己署名証明書では「発行元不明」の警告自体は解消されません。

ドラッグ&ドロップ

ウィンドウへファイルをドロップすると内容(拡張子ではなく中身)を自動判定し、自プロジェクト/タブエクスポート/FUJI/SKB/dos.txt/音声ファイルのいずれかとしてインポート処理へ振り分けます。プロジェクトファイルと音楽ファイルを同時にドロップした場合、プロジェクトを開いてから音楽を読み込む順で処理されます。音楽ファイルは開いているプロジェクトが無いと読み込めません。判定できないファイルは無視されます。

FUJIインポートの詳細

読み込んだファイルからdifDataの候補行をスキャンし、1つのダイアログで以下を設定します。

  1. キー種: FUJI側の記載は一切参照せず、テンプレートフォルダに存在するキー種一覧から選択
  2. 難易度名: difDataの全行から拾った難易度名の候補、または「後で設定する」「今設定する」(手入力欄が表示されます)から選択

インポート後、既存プロジェクトへの追加/新規プロジェクトとして開く/キャンセルを確認します。

タブ・ウィンドウ構成

  • プロジェクトタブ(上段)・難易度タブ(下段)の2段構成。ドラッグで並べ替え可能(同一グループ内のみ)
  • 「新規譜面を追加」ボタンで難易度タブを追加(キー種・難易度名・BPM入力、新規プロジェクトと同じダイアログ)
  • タブを閉じるには最低1タブが残っている必要があり、閉じる操作はUndo不可(確認あり)
  • 譜面ビューと右パネルの境目はドラッグで幅を調整できます

譜面編集(マウス)

StartNumber編集モード時

他の編集操作より優先して以下のみ有効になります。

  • 左ドラッグ: 波形に対して譜面全体をスライドしStartNumberを調整(Reverse時は方向が反転)
  • 左クリック(ドラッグなし): ガイド線を配置/移動
  • ドラッグ終了時、最寄りの小節線から10px以内ならStartNumberがぴったり整列
  • 右クリック・中クリックはこのモードでは無効

ミニマップ

譜面ビュー右側に全体構成を表示(ノートは白い短線、フリーズは水色の帯)。クリックでその位置を画面中央にスクロールジャンプ、ドラッグで連続的にスクラブ移動できます。操作後は自動的にキーボードフォーカスが譜面ビュー側へ戻ります。

時間情報レーンの範囲選択・ループ再生

譜面ビュー左端の時間情報レーン(小節番号/frame/time表示)を左ドラッグすると、時間軸上の範囲(開始tick〜終了tick)を選択できます。オブジェクトそのものを選択するわけではなく、あくまで「区間」を指定する汎用機能で、以下の2つの用途で使われます。

  • 始点・終点はドラッグ後も個別に上下へつまんで動かせます
  • 範囲の解除はEscapeキー(下記「常時ショートカット」参照)

レーン入替マクロへの適用

右パネル「マクロ」タブでマクロを実行する際、時間情報レーンで範囲が選択されていれば「その範囲内のみ」にマクロを適用し、範囲が未選択であれば難易度タブ全体に適用します(範囲・タブ全体のいずれの場合も、フリーズアローが範囲境界をまたいでいる場合は警告ダイアログが出ます)。

DAWループ再生(目視テスト専用)

上部パネルに「ループ再生(目視テスト)」の行があり、選択中の範囲の始点・終点をframe換算した値が表示されます。「ループ ON/OFF」トグルは範囲選択中のみ有効で、既定はOFFです。

  • ONの間、目視テストの再生位置がループ終点frameに到達すると、ループ始点frameへ戻ってそのまま再生を続けます(停止しません)
  • 目視テストはあくまで通常通り「再生開始ライン」から始まります。ループの始点・終点はループ処理にのみ使われ、開始位置そのものは変わりません
  • 範囲選択を解除するとループも自動的にOFFになります
  • プレイテストには適用されません(目視テストのみ)

ゲージ設定

右パネル「プロジェクト」タブの「ゲージ設定...」ボタン(BPMとStartNumberの間)から開き、難易度タブを選んでからそのタブ内で設定します。

先頭のスイッチ

「dos作成後に直接編集する」をONにすると、以下の全設定が無効化され、エクスポート時にゲージ関連ヘッダーを一切出力しません(書き出し後のdos.txtへ自分で追記する運用向け)。

タブごとの設定(併存可能)

  • 本体ゲージ(difData直接指定): チェックONでノルマ(x指定または0〜100の数値)/回復量/ダメージ/初期ライフ(空欄可)を上書き
  • 切替候補ゲージ(customGauge): 「指定しない」/「継承キーワード使用(survival・border・customDefault)」/「明示リスト指定(ゲージ名・可変V・表示名を行ごとに編集)」の3択

プロジェクト全体共有の設定

  • gaugeXXXパラメータ表: ゲージ名ごとに難易度タブ列でCSV(ノルマ,回復,ダメージ,初期ライフ)を入力。「ゲージ名を追加」ボタンあり
  • 直接入力モード: テキストボックスに入力すると他の全設定を無視し、その文字列がそのままdos.txtへ出力される(過去資産のコピペ用途)

ゲージ計算機

ゲージ設定ウィンドウの「ゲージ計算機を開く...」から起動するモードレスの計算機です。所有ウィンドウで選択中の難易度タブに自動で追従します。

  • MAX Life/ノルマ%/通常ノート数・フリーズ数(自動取得)/初期ライフ%、「フリーズ始点判定を含める」チェックを入力
  • 対象ゲージ名・Fix(固定値)またはVary(ノーツ数按分)モードで回復・ダメージ値を設定すると、必要達成率・許容ミス数を自動算出
  • 逆に目標達成率またはミス数から回復・ダメージ値を逆算する「設計モード」も搭載(ダメージ固定/回復固定を選択可)
  • 「選択中のゲージ名へ適用」ボタンでゲージ設定ウィンドウのパラメータ表へ書き戻し可能

プレイテスト(Ctrl+P)

  • 判定表示: イイ/シャキン/マターリ/ショボーン/ウワァン(通常ノート系)、キター/イクナイ(フリーズ系)。通常ノートとフリーズは別管理でコンボ表示
  • ステップゾーンのヒットフラッシュ: 判定確定時、該当レーンのノート画像を一回り大きく半透明で数フレーム表示
  • キー操作: 使用中のキー種テンプレート(選択中のキーパターンがあればそれを反映)のキー割り当てに準拠。押しっぱなしはリピート判定しない
  • 中断キー: Delete/Escapeを個別にON/OFF設定可能(最低1つは必須)。BackSpaceは中断キーではなく「再生開始フレームからやり直し」専用キー(判定・コンボ・打鍵状態を全てリセットして再開)
  • 起動時ウェイト(ms): プレイテスト画面表示後、指定時間だけ待ってから再生を開始(環境設定で設定、既定0=待たない。BackSpaceでのやり直し時も同様に適用される)
  • キーパターン: 環境設定で選択中のキー種別パターンを反映(プレイテストの見た目・キー入力のみに影響し、譜面編集画面やdos.txt出力には影響しない)
  • AutoPlay有効時は全ノートをジャストタイミングで自動判定し、手動キー入力は中断/やり直しキー以外無効になる
  • Reverse・HiSpeed・調整フレーム(オフセット)・ウィンドウ倍率・再生速度・ノート音も反映
  • ウィンドウ幅: dos.txtのplayingWidth指定があれば最優先。無ければ環境設定「ウィンドウ幅」の設定(自動/直接入力/キー種から選択)に従う

ライフゲージやリザルト画面は無く、判定文字とコンボ表示のみのシンプルな構成です。

プレイ画面プレビュー(右パネル「プレビュー」タブ)

プレイテスト画面の見た目をそのまま右パネルへ再現する、判定なしの仮想スナップショットです。プレイテスト用の設定(Reverse・ハイスピード・調整オフセット・キー種の幅・speed_data/boost_data等)を反映した見た目で、現在の難易度タブの全ノート・フリーズ・色編集(ncolor_data)を表示します。

  • 通常時は再生開始ラインの位置での静止スナップショットを表示
  • 目視テスト中は再生位置に連動してリアルタイムに動きます(プレイテスト中は連動しません)
  • 判定・コンボ・ノートの消去は行わない、あくまで見た目の確認用です

プレイテスト

  • Reverse(既定)、ハイスピード(x0.25〜x10)、タイミング調整オフセット(frame)、ウィンドウサイズ倍率

マクロ・歌詞レーン

マクロ(レーン入れ替え)

右パネル「マクロ」タブから、レーン入れ替えマクロの追加・編集・削除・実行が行えます。実行は現在の難易度タブに対してUndo可能な形で適用されます。時間情報レーンで範囲選択中であれば「その範囲内のみ」、未選択であればタブ全体に適用されます(詳細は「時間情報レーンの範囲選択・ループ再生」参照)。

  • マクロ編集ウィンドウ: 対象キー種・マクロ名を指定し、「元のレーン(並び替え不可)」と「入れ替え後(ドラッグで並び替え)」の2段プレビューで入れ替え内容を作成
  • 対象キー種を変更すると入れ替え後プレビューがリセットされる旨の確認ダイアログが表示される
  • マクロ定義はキー種ごとに別ファイル(s-macro_キー種.json)として保存されます(下記「保存される情報」参照)

歌詞レーンの管理(設定メニュー)

modeless(開いたまま譜面ビューで歌詞エントリの配置・編集が可能)なウィンドウです。

  • 「+ 歌詞レーンを追加」で新規レーンを追加(自動命名)
  • 各レーンごとに名前の変更・「Reverse専用」フラグ・削除が可能(削除は既存エントリがある場合のみ確認ダイアログが出ますが、Ctrl+Zで元に戻せます)
  • 歌詞オブジェクトを選択すると右パネル「オブジェクト」タブで段(上段/下段)・フェードフレーム数等を編集可能

異なるキー種間のコピー(コピーマネージャー)

コピー元タブとペースト先タブでキー種が異なり、かつコピー内容にノート・フリーズが含まれる場合、Ctrl+V実行時に自動で「コピーマネージャー」ウィンドウが開きます(キー種が同じ場合や、コピー内容がマーカー・speed・boost・BPMのみ等レーンに依存しないものだけの場合は、従来通りそのまま貼り付けられます)。

ウィンドウの構成

  • コピー元レーン(上段): コピー内容に実際にノート・フリーズを含むレーンだけを表示
  • 配置レーン(中段): ペースト先のレーン数と同じ数のセル。上段のレーンをドラッグ&ドロップして「どのレーンへ置くか」を指定します
  • コピー先レーン(下段): ペースト先タブの全レーンを参照表示(配置レーンの真下に対応)
  • 同じコピー元レーンを複数の配置レーンへ割り当てる(複製)、複数のコピー元レーンを同じ配置レーンへ割り当てる(統合)、いずれも可能です
  • 割り当ての解除は、配置レーン上のアイコンを「レーン領域外へドラッグ」「右クリック→削除」「×ボタン」のいずれかで行えます
  • 「実行」時、コピー元の全レーンが配置されていない場合は確認ダイアログが表示されます(OKでそのまま実行、キャンセルでウィンドウに戻る)
  • 「キャンセル」ボタンまたはウィンドウを閉じると、貼り付け自体を中止できます

配置時の衝突解決

複数のコピー元レーンを同じ配置レーンへ割り当てた場合や、貼り付け先に既存のノート・フリーズがある場合、配置しようとした位置が重なることがあります。同一レーン・同一tickへ通常ノートが2つ以上重なる場合は2つ目以降を無視しますが、それ以外の6パターンの衝突は、ウィンドウ内の折りたたみ「コピー・ペースト設定」で解決方法を選べます(設定は環境設定とは別に保存され、次回以降のコピーマネージャーにも引き継がれます)。

衝突パターン選択肢
通常ノート + フリーズ先頭通常ノートを優先 / フリーズを優先
通常ノート + フリーズ帯通常ノートの16分手前でフリーズアローを切る / 通常ノートを無視する
通常ノート + フリーズ終端通常ノートの16分手前でフリーズアローを切る / 通常ノートを無視する
フリーズ先頭 + フリーズ先頭長い方を残す / 短い方を残す
フリーズ先頭 + フリーズ帯後ろのフリーズアローの16分手前で切る / 後ろのフリーズアローを無視
フリーズ先頭 + フリーズ終端後ろのフリーズアローの16分手前で切る / 後ろのフリーズアローを無視

同じ折りたたみ内の「プロパティの維持」設定で、色編集モードの色情報・コメント/警告注釈を新しいレーンへ引き継ぐかどうか(持ち越す/持ち越さない)も選べます。
