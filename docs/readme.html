エディタについて

danoniplus互換の譜面ファイル(dos.txt)を作成するための編集ソフトです。1ウィンドウ=1曲(複数難易度タブを内包)構成で、FUJIエディタ・SKBエディタ・既存dos.txtからのインポートにも対応しています。

ドラッグ&ドロップ

ウィンドウへファイルをドロップすると内容を自動判定し、自プロジェクト/タブエクスポート/FUJI/SKB/dos.txt/音声ファイル/Base64埋め込み音楽/不明のいずれかとしてインポート処理へ振り分けます。

FUJIインポートの詳細

読み込んだファイルからdifDataの候補行をスキャンし、1つのダイアログで以下を設定します。

  1. キー種: FUJI側の記載は一切参照せず、テンプレートフォルダに存在するキー種一覧から選択
  2. 難易度名: difDataの全行から拾った難易度名の候補、または「後で設定する」「今設定する」(手入力欄が表示されます)から選択

インポート後、既存プロジェクトへの追加/新規プロジェクトとして開く/キャンセルを確認します。

タブ・ウィンドウ構成

  • プロジェクトタブ(上段)・難易度タブ(下段)の2段構成。ドラッグで並べ替え可能(同一グループ内のみ)
  • 「新規譜面を追加」ボタンで難易度タブを追加(キー種・難易度名・BPM入力)
  • タブを閉じるには最低1タブが残っている必要があり、閉じる操作はUndo不可(確認あり)

その他

  • 編集中はIME(日本語入力)を自動的に無効化(Space等のショートカットがIMEに奪われないように)
  • タイム情報レーン/マーカーレーンの文字サイズは環境設定で変更可能(既定8.0pt/9.0pt)
  • スナップに連動したカーソルライン表示、選択オブジェクトの黄色ハイライト、譜面ビューの反転(Reverse)表示に対応

ミニマップ

譜面ビュー右側に全体構成を表示。クリックでその位置を画面中央にスクロールジャンプ、ドラッグで連続的にスクラブ移動できます。操作後は自動的にフォーカスが譜面ビュー側へ戻ります。

ゲージ設定

「設定 > ゲージ設定」から開き、難易度タブを選んでからそのタブ内で設定します。

タブごとの設定(併存可能)

  • 本体ゲージ(difData直接指定): チェックONでノルマ(x指定または0〜100の数値)/回復量(既定6)/ダメージ(既定40)/初期ライフ(空欄可)を上書き
  • 切替候補ゲージ(customGauge): 「指定しない」/「継承キーワード使用(survival・border・customDefault)」/「明示リスト指定(ゲージ名・可変V・表示名を行ごとに編集)」の3択

プロジェクト全体共有の設定

  • gaugeXXXパラメータ表: ゲージ名ごとに難易度タブ列でCSV(ノルマ,回復,ダメージ,初期ライフ)を入力
  • 生の上書き設定: テキストボックスに入力すると他の全設定を無視し、その文字列がそのままdos.txtへ出力される

「dos作成後に直接編集する」

ONにすると、本体ゲージ・切替候補ゲージ・パラメータ表・生の上書き入力欄まで全て無効化し、エクスポート時にゲージ関連ヘッダーを一切出力しません(書き出し後のdos.txtへ自分で追記する運用向け)。

ゲージ計算機

ゲージ設定ウィンドウの「ゲージ計算機を開く...」から起動するモードレスの計算機です。

  • MAX Life/ノルマ%/通常ノート数・フリーズ数(自動取得)/初期ライフ%を入力
  • 対象ゲージ名・Fix(固定値)またはVary(ノーツ数按分)モードで回復・ダメージ値を設定すると、必要達成率・許容ミス数を自動算出
  • 逆に目標達成率またはミス数から回復・ダメージ値を逆算する「設計モード」も搭載
  • 「選択中のゲージ名へ適用」ボタンでゲージ設定ウィンドウのパラメータ表へ書き戻し可能

プレイテスト(Ctrl+P)

  • 判定表示: イイ!!/シャキン/マターリ/ショボーン/ウワァン!!(通常ノート系)、キタ-!!/イクナイ(フリーズ系)。通常ノートとフリーズは別管理でコンボ表示
  • ステップゾーンのヒットフラッシュ: 判定確定時、該当レーンのノート画像を一回り大きく(+30px)半透明(75%不透明度)で数フレーム表示
  • キー操作: 使用中のキー種テンプレートのキー割り当てに準拠
  • 中断キー: Delete/BackSpace/Escapeを個別にON/OFF設定可能(最低1つは必須)
  • AutoPlay有効時は全ノートをジャストタイミングで自動判定
  • Reverse・HiSpeed・調整フレーム(オフセット)・ウィンドウ倍率・再生速度も反映

ライフゲージやリザルト画面は無く、判定文字とコンボ表示のみのシンプルな構成です。

分析タブ

累計配置オブジェクト数が10,000に達すると出現する隠し機能です。

  • 「分析を実行」: ITTNアナライザー(danoniplus analyze.jsの移植)によるSTREAM/VOLTAGE/CHORD/FREEZE/SOF-LAN/ONIGIRI等のスコアと総合レーティングを表示
  • 「算出・再算出」: ボタンを10回押すまで結果が表示されない二段階ロック。到達後は信頼区間付きの「おにスター」推定値を表示

マクロ(レーン入れ替え)

マクロタブから、レーン入れ替えマクロの追加・編集・削除・実行が行えます。実行は現在の難易度タブに対してUndo可能な形で適用されます。
