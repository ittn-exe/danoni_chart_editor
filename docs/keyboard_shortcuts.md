# キーボード操作一覧(2026-07-26)

`src/DanoniEditor.App/MainWindow.xaml.cs` の `MainWindow_PreviewKeyDown` /
`HandleKeyboardModeKey` の実装に基づく、キーボードで行える操作の一覧。テキスト入力欄
(TextBox等)にフォーカスがある間は、Ctrl系の一部を除きほとんどのショートカットが無効になる
(通常のテキスト編集操作を優先するため)。

## 1. 常時有効なショートカット(Ctrl+◯◯)

マウスモード・キーボードモードのどちらでも常時有効。

| キー | 動作 |
|---|---|
| Ctrl+Z | 元に戻す(Undo) |
| Ctrl+Y | やり直し(Redo) |
| Ctrl+S | プロジェクト保存 |
| Ctrl+E | dos.txtエクスポート |
| Ctrl+Home | 譜面先頭(tick0)へスクロール |
| Ctrl+End | 末尾ノートを画面中央へスクロール |
| Ctrl+Space | (目視テスト中のみ)現在位置で目視テストを終了 |
| Ctrl+P | プレイテスト開始 |
| Ctrl+, | キーボードモードのON/OFF切替 |
| Ctrl+X | 選択範囲を切り取り(テキスト入力欄フォーカス中は通常のテキストコピペを優先) |
| Ctrl+C | 選択範囲をコピー(同上) |
| Ctrl+V | 貼り付け(同上) |
| Ctrl+A | ノート・フリーズアローを全選択(テキスト入力欄フォーカス中は無効) |
| Shift+Ctrl+A | 環境設定で指定した対象種別(ノート/フリーズ/speed/boost/BPM/拍子/マーカー)を全選択 |
| Ctrl+1〜9,0,-,^ | グリッド分解能(スナップ)を切り替え(詳細は4章) |

キーボードモードON中のみ追加で有効:

| キー | 動作 |
|---|---|
| Ctrl+← | カーソルを2小節分戻す |
| Ctrl+→ | カーソルを2小節分進める |
| Shift+Ctrl+← | カーソルを4小節分戻す |
| Shift+Ctrl+→ | カーソルを4小節分進める |

## 2. 常時有効なショートカット(修飾なし)

テキスト入力欄フォーカス中は無効。キーボードモードON中は、このうち **Space** と
**Backspace** はキーボードモード側の操作(3章)に奪われ、下記の動作は発生しない。

| キー | 動作 |
|---|---|
| PageUp | 1画面分上へスクロール |
| PageDown | 1画面分下へスクロール |
| Delete | 選択中オブジェクトを削除 |
| Backspace | 再生開始フレームをリセット(※キーボードモードON中は3章の「カーソル位置削除」に置き換わる) |
| Space | 目視テストの開始/終了(※キーボードモードON中は3章の「カーソル前進」に置き換わる) |

## 3. キーボードモード専用操作(Ctrl+,でON、SKB操作モード準拠)

キーボードモードON中のみ有効。マウスモードの同キー(2章)より優先して処理される。

| キー | 動作 |
|---|---|
| ↑ | カーソル後退(画面上方向) |
| ↓ | カーソル前進(画面下方向) |
| Space | カーソル前進(tick順方向、Danoni系エディタの慣習) |
| B | カーソル後退(tick順方向) |
| ← | 1小節戻る(小節途中なら現在の小節頭へ、既に小節頭なら1つ前の小節頭へ) |
| → | 1小節先へ |
| Backspace | カーソル位置のノート/フリーズを削除 |
| (レーンごとの入力キー) | カーソル位置にノートを配置/解除 |
| Shift+(レーンごとの入力キー) | フリーズの開始/終了をトグル |

※ ↑/↓とSpace/Bは見た目上どちらも「前後」に対応するが、↑/↓は画面上の見た目方向
(TickToYの並び)、Space/Bはtickの前後方向そのものを表しており、意図的に別の基準になっている
(2026-07-25確定)。

### レーンごとの入力キー(標準5keyの例)

各キー種のテンプレート(`template/temp_*.json`)の`keyboardInputKeys`で個別に設定されている。
5key標準テンプレートの例:

| レーン | キー |
|---|---|
| left | J |
| down | K |
| up | I |
| right | L |
| space | G |

他のキー種(7/9/11/13key等)は各`temp_*.json`で個別設定。同時押しとみなす時間閾値
(既定30ms)は環境設定の「SKB操作モード」カテゴリで変更できる。

## 4. グリッド分解能ショートカット(Ctrl+1〜9,0,-,^、2026-07-26)

譜面ビューのグリッド分解能(スナップ)をキーボードから直接切り替える機能。マウスモード・
キーボードモードのどちらでも常時有効(SKBエディタの操作感に合わせ、モードに依存しない)。
選択すると自動的にスナップもONになる。エディタ本体にボタン/チェックボックス等のUIは無く、
**環境設定(設定 > 環境設定 > キーボードモード)の「グリッド分解能ショートカット」でキー割り当て
セットを選ぶ**(オリジナルセット/SKB拡張セットの2択)。

物理キーの位置(Ctrl+1,2,...,9,0,-,^の順)は両セット共通。「^」はJIS配列で「0」の右隣にある
キー(WPFの`Key.OemPlus`)。

| 物理キー | オリジナルセット | SKB拡張セット |
|---|---|---|
| Ctrl+1 | 4分 | 4分 |
| Ctrl+2 | 8分 | 8分 |
| Ctrl+3 | 12分 | 16分 |
| Ctrl+4 | 16分 | 12分 |
| Ctrl+5 | 20分 | 24分 |
| Ctrl+6 | 24分 | 48分 |
| Ctrl+7 | 28分 | 32分 |
| Ctrl+8 | 32分 | 20分 |
| Ctrl+9 | 40分 | 28分 |
| Ctrl+0 | 48分 | 40分 |
| Ctrl+- | 56分 | 56分 |
| Ctrl+^ | 64分 | 64分 |

- **オリジナルセット**(既定): 分解能の値を単純に昇順で並べたもの。このエディタで初めて
  キーボード操作を使う人向け。
- **SKB拡張セット**: SKBエディタのCtrl+1〜7割り当て(4/8/16/12/24/48/32分)をそのまま踏襲し、
  SKBに存在しない8個目以降(20/28/40/56/64分)は昇順で追加したもの。SKBエディタから
  乗り換えた人が指の記憶をそのまま使える。

実装: `src/DanoniEditor.Core/Settings/GridShortcutPresets.cs`(プリセット定義)、
`src/DanoniEditor.App/MainWindow.xaml.cs` の `GridShortcutKeyIndex`/`ApplyGridShortcut`
(キー入力の処理)、`src/DanoniEditor.Core/Settings/AppSettings.cs` の `GridShortcutPreset`
(選択状態の永続化)。
